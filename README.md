# واجهة نزّل — React + Vite

واجهة عربية RTL متجاوبة لاكتشاف الروابط وعرض خيارات تنزيل الملفات والوسائط أو حفظ صفحة ويب. هذه الواجهة هي الجزء الأمامي فقط؛ يلزم تشغيل API خلفي متوافق معها لإجراء التحليل والتنزيل.

## التشغيل محليًا

- يتطلب Node.js 20 أو أحدث.
- ثبّت الحزم: `npm install`
- شغّل بيئة التطوير: `npm run dev`
- أنشئ نسخة الإنتاج: `npm run build`

## اتصال الواجهة بالخادم

افتراضيًا ترسل الواجهة الطلبات إلى نفس النطاق. لتحديد نطاق API منفصل، أنشئ ملف `.env`:

```env
VITE_API_BASE_URL=https://your-api.example.com
```

تتوقع الواجهة العقد التالي:

- `POST /api/analyze` مع JSON بالشكل `{ "url": "https://..." }`، ويرجع معلومات المحتوى مثل `kind`, `title`, `mimeType`, `size`, و`supportsMediaExtraction`.
- `GET /api/download?url=...&mode=direct|media|page` لبدء التنزيل.

يجب أن ينفذ الخادم فحصًا آمنًا للروابط العامة، ومنع الوصول إلى عناوين الشبكات الداخلية، والتحقق من صلاحية التنزيل وحجمه. لا تضع أسرارًا أو مفاتيح خاصة في متغيرات `VITE_*` لأنها تُضمّن في ملفات الواجهة العامة.
